# BK's YoseTrainer

A simple web trainer for practicing yose (endgame) in Go.

The goal of the project is to provide a focused, distraction-free environment for solving yose problems — similar to Anki, but with an interactive board.

---

## 🧠 What you can do

- Solve yose positions on a Go board
- Evaluate:
  - the best move
  - point value
  - result type (sente / gote / etc.)
- Review variations in different modes:
  - **Guided** — you play, system responds
  - **Step** — go through moves one by one
  - **Self** — reproduce the variation yourself

---

## 🎯 Philosophy

This tool is intentionally minimal.

No timers, no pressure — just focused thinking.

Designed to help you:

- improve endgame reading
- develop positional judgment
- build intuition for sente / gote

---

## 🛠 Tech stack

- React + TypeScript
- Vite
- Styled Components
- Custom SVG Go board

---

## 🚀 Run locally

